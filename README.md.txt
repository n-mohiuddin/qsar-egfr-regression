# QSAR EGFR Regression

QSAR regression pipeline for predicting EGFR kinase inhibitory potency (pIC50) from ChEMBL IC50 data using machine learning.

## Contents
- `notebooks/`: Jupyter notebooks
- `data/`: (ignored) raw/processed data should not be committed
- `reports/figures/`: exported plots (optional)
